# 01 硬件选型与原理

## 1. 系统框图

```
                 ┌──────────────────────────────┐
   电池 B+ ──────┤ VC3(VC4/VC5 短接)            │
   电池 B2 ──────┤ VC2                          │
   电池 B1 ──────┤ VC1          BQ76920         │
   电池 B- ──┬───┤ VC0 / VSS                    │
             │   │                              │
             │   │  SRP/SRN ◄── 2mΩ 采样电阻 ────┼── 电池负极
             │   │                              │
             │   │  CHG ──► N-MOS ─┐             │
             │   │  DSG ──► N-MOS ─┴── PACK-     │
             │   │                              │
             │   │  SDA/SCL/ALERT/BOOT ─────────►├── STM32F103
             │   │  TS1 ◄── 10k NTC             │
             │   └──────────────┬───────────────┘
             │                  │ REGOUT/3.3V
             └──── 3.3V LDO ◄───┘
```

要点：**采样电阻和两个 MOS 都在负极（低边）**，B+ 直通负载；充电器从 PACK+/PACK- 接入。

## 3. 关键电路注意点

### 3.1 AFE 外围
- **VC0~VC3 每根都要 RC 滤波**：100Ω 串 + 0.1µF 到 VSS，电阻和电容**紧贴 AFE 引脚**，
  这是抑制电芯引线电感和瞬态的关键，不要省。
- **3S 时 VC4/VC5 必须短接到 VC3**（数据手册要求，否则读数异常）。
- **SRP/SRN 用开尔文接法**：从采样电阻焊盘内侧单独引两根线，不要和功率走线共用。
- **BOOT 引脚**：上电/唤醒靠它拉高 ≥2ms；本设计由 MCU 驱动，之后必须释放成高阻，
  否则会影响内部温度测量（代码里已处理）。
- **ALERT**：高有效，MCU 端配置为下拉 + 上升沿中断。
- **REGOUT**：AFE 内部稳压输出，只做参考/上拉用，不要拿它给 MCU 供电。

### 3.2 功率回路
- 两个 N-MOS **背靠背**串联（共源或共漏，按参考设计），栅极由 AFE 的 CHG/DSG 驱动；
- 走线按 **10A 连续**设计：2oz 铜、宽度 ≥4mm，或开窗加锡；
- 电池负极 → 采样电阻 → DSG → CHG → PACK-，顺序不要颠倒，否则库仑计符号会反。

### 3.3 大电容负载与预充
如果负载端有大电容（比如电机驱动），直接合闸会有巨大浪涌，SCD 会天天误跳。
加一条 **100Ω/2W 预充电阻 + 小 MOS**（或直接用 PTC）先给电容充电 100ms，再开主 MOS。

### 3.4 充电器接口
BMS 不负责 CC/CV。外部用 12.6V 恒压恒流充电器（2A），BMS 只通过 CHG MOS 决定通断。
若要板载充电，另加 BQ25895 之类的充电 IC，与本 BMS 并联即可。

## 5. PCB 布局

1. 功率路径（电池-、采样电阻、两个 MOS、PACK-）放一侧，**大面积铺铜**；
2. AFE 放采样电阻附近，SRP/SRN 差分对**等长、包地**，远离 MOS 漏极；
3. VC 滤波的 100Ω+0.1µF 紧贴 AFE，电芯引线先过 RC 再进芯片；
4. 晶振下方挖空、包地，远离 I2C 和 MOS；
5. NTC 贴在电芯表面/MOS 散热片上，走线用差分或至少远离功率环路；
6. 4 层板推荐叠层：TOP(信号+功率) / GND / PWR / BOTTOM(功率)，2 层也能做但要小心地弹。

## 6. 安全与合规

- **锂电不是玩具**：过充、短路、机械损伤都会热失控。第一次上电必须限流 + 串保险丝，
  人不要离开，旁边备灭火毯/沙桶。
- 单体 4.25V 跳闸只是**保护**，正常充电截止仍由充电器 4.2V/CV 完成。
- 均衡电阻会发热（3 节同时 ≈0.36W），周围不要贴塑料件。
- 商用产品需过 **IEC 62133 / GB 31241**，本设计是学习原型，不替代认证。
- 焊接 BQ76920（TSSOP）注意静电，烙铁接地；焊完先量各引脚对地阻抗再上电。

## 7. 和 Echo-Mate 的关系

上一轮那台 RV1106 桌面机器人是 USB 5V 供电、没有电池管理。若想让它脱离线缆：
- 3S 太重，实际应做 **1S + 升压**或 **2S + 降压**；
- 本项目的 AFE 换成 **BQ76920 的 3S 配置不能直接用于 1S**，1S 应改用 CW2015/MAX17048 电量计 +
  TP4056/IP5306 充电；
- 但保护状态机、SOC 算法、上报协议这三块代码可以直接复用（把 `BMS_CELL_COUNT` 改 1，
  换掉底层采样即可）。
