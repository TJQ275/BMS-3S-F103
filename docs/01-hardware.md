# 01 硬件选型与原理（v2，已修正 v1 的接线错误）

> ⚠️ **v1 有 6 处会烧板子或逻辑不通的地方，本文已修正**，修正清单见最后一节。
> 如果你按 v1 画过原理图，请对照第 9 节逐条核对。

## 1. 系统框图

```
   电池 B+ ──────┬── VC3 (3S 时 VC4/VC5 短接到这里)
   电池 B2 ──────┼── VC2
   电池 B1 ──────┼── VC1
   电池 B- ──┬───┴── VC0 / SRP          ┌─────────────┐
             │                          │  BQ76920    │
             │  ┌──────────┐            │  VSS = 系统地│
             └──┤ 2mΩ 采样 ├──┬─────────┤  SRN        │
                └──────────┘  │         └──────┬──────┘
                              │                │ CHG / DSG
                         VSS（IC 地）           ▼
                              │        ┌── N-MOS ──┬── N-MOS ──┐
                              └────────┤   DSG     │   CHG     ├── PACK-
                                       └───────────┴───────────┘
```

**三个关键点（v1 写错过）**：

1. **IC 的地（VSS）不是电池负极**，而是"采样电阻之后、MOS 之前"那个节点；
   VC0/SRP 接电池负极侧，SRN/VSS 接 MOS 侧。接反 → 库仑计恒为 0、总压也不对。
2. 电流路径：`B- → 采样电阻 → VSS 节点 → DSG → CHG → PACK-`，顺序不能颠倒。
3. B+ 直通负载，充电器从 PACK+/PACK- 接入。

## 3. 关键电路注意点

### 3.1 AFE 外围

- **地参考**：VSS = 采样电阻与 MOS 之间的节点（系统地）；VC0/SRP = 电池负极侧。
  这是 v1 最大的错误——原图画成 `VC0/VSS 都接 B-`，那样库仑计读不到任何电流。
- **VC 滤波要"差分"**：每根 VCx 串 100Ω；**相邻两根 VCx 之间**跨接 0.1µF（不是每根对地各一个），
  VC3~VSS 之间再补一个 0.1µF。单端对地滤波会把引线电感和共模噪声放进 ADC。
- **3S 时 VC4/VC5 短接到 VC3**。
- **TS1 只接 NTC 到 VSS**：AFE 内部已有偏置，**不要再并 10k 上拉**，否则温度整体偏低。
  MCU 侧那两路 NTC 才需要外部 10k 上拉。
- **BOOT**：MCU 驱动，拉高 ≥2ms 后释放成高阻；**加 100k 下拉**，避免悬空被噪声误触发。
- **ALERT**：上板第一件事是量这个脚的电平类型。
  推挽高有效 → MCU 下拉 + 上升沿（本工程默认）；若是开漏 → 必须改上拉 + 下降沿，
  否则永远收不到中断（而且不会报错，只会"保护慢半拍"）。
- **I2C 上拉接 REGOUT，不要接 3.3V**：AFE 进 SHIP 时 REGOUT 为 0，避免通过上拉给 AFE 反灌电。
- **REGOUT 只做参考/上拉**，不要给 MCU 供电。

### 3.2 功率回路

- 两个 N-MOS **源极对接（共源）**，两个漏极分别接 VSS 和 PACK-。
  接成共漏也能"通"，但体二极管方向反了，**关断后仍有一路导通**，等于关不断。
- **验证方法**：两管都关断时，万用表二极管档量 PACK- 与 VSS，**两个方向都应不通**。
- 8A 持续、2×5mΩ 导通损耗约 0.64W，DFN5×6 + 2oz 铜要留散热焊盘。
- 走线按 10A 设计：2oz 铜、宽度 ≥4mm，或开窗加锡。

### 3.3 大电容负载与预充

- 负载端有大电容时，直接合闸的浪涌会让 SCD 天天误跳。
- 预充电阻 **100Ω/2W 必须串一个 MOS/继电器**，只在合闸前接通 100ms；
  **不能常接**，否则一直漏电发热。

### 3.4 充电器接口（v1 这里会烧 IO）

- ❌ **不要把 12.6V 直接接到 MCU 的 PB5**，会击穿 IO。
- ✅ 本工程固件已改成**用电流方向判断是否在充电**（`I > +50mA` 视为充电中），
  CHG_DET 这个脚可以不用。
- 如果一定要用引脚检测：**100k/22k 分压 + 3.3V 钳位二极管**，并确认 9V（最低电量）时
  分压值仍高于 VIH（≈2.0V）。更稳的是光耦或比较器。

### 3.5 最小系统别漏了这些

| 项 | 后果 | 做法 |
|---|---|---|
| **BOOT0 下拉** | 悬空可能进 Bootloader，程序不跑 | 10k 到 GND |
| **SWD 排针** | 第一次烧录都费劲 | 3.3V/SWDIO/SWCLK/GND |
| **晶振负载电容** | 起振不稳 | 2×20pF |
| **复位电容** | 上电抖动 | NRST 100nF 到地 |
| **电池反接保护** | 直接烧 AFE | 防呆接插件；有条件加 P-MOS 理想二极管 |

## 5. PCB 布局

1. 功率路径（B-、采样电阻、两 MOS、PACK-）放一侧，大面积铺铜；
2. AFE 紧贴采样电阻，SRP/SRN 差分对等长包地，远离 MOS 漏极；
3. VC 滤波的 100Ω + 0.1µF 紧贴 AFE，电芯线先过 RC 再进芯片；
4. 晶振下方挖空包地，远离 I2C 与 MOS；
5. NTC 贴电芯表面/MOS 散热片，走线远离功率环路；
6. 推荐 4 层：TOP / GND / PWR / BOTTOM。

## 6. 上电前自检清单（必做）

- [ ] 万用表二极管档：PACK- 与 VSS **两个方向都不通**（MOS 关断状态）
- [ ] 万用表二极管档：B- 与 VSS 之间只有采样电阻（≈2Ω 以内）
- [ ] VC0 对 B- = 0Ω；VC0 对 VSS ≠ 0Ω（否则地接错了）
- [ ] BOOT 对地 ≈100k；BOOT0 对地 ≈10k
- [ ] 3.3V 对 GND 不短路；REGOUT 对 GND 不短路
- [ ] 每节 VCx 对相邻 VC(x-1) 的电容已焊（差分滤波）
- [ ] 首次上电：12V 限流 50mA + 串保险丝，手不离电源开关

## 7. 安全与合规

- 锂电过充/过放/短路/机械损伤都会热失控，第一次上电必须限流 + 有人看护；
- 单体 4.25V 跳闸只是保护，正常截止仍由充电器的 4.2V/CV 完成；
- 均衡电阻会发热（3 节同时 ≈0.36W），周围不要贴塑料件；
- 商用需过 IEC 62133 / GB 31241，本设计是学习原型；
- 焊接 TSSOP 封装注意静电，焊完先量各脚对地阻抗再上电。

## 8. 和 Echo-Mate 的关系

- 3S 对桌面机器人太重，实际应做 1S + 升压 或 2S + 降压；
- 1S 不能用 BQ76920 的 3S 配置，应改 CW2015/MAX17048 + TP4056/IP5306；
- 但保护状态机、SOC 算法、上报协议可直接复用（`BMS_CELL_COUNT` 改 1，换底层采样）。
