# 04 校准、测试与验收

> 全程遵守：**先限流、再上电；先空载、再带载；先单节、再整组。**

## 1. 上电前检查（不接电池）

| 检查项 | 方法 | 合格标准 |
|---|---|---|
| 电源短路 | 万用表电阻档量 3.3V 对 GND | >1kΩ |
| PACK+ 对 PACK- | 电阻档 | 不短路（MOS 关断时应为高阻） |
| VC0~VC3 对 VSS | 二极管档 | 无短路 |
| 采样电阻 | 四线法 | 2.0mΩ ±1% |
| 焊点 | 放大镜 | BQ 引脚无连锡（TSSOP 易连） |

## 2. 分阶段上电

1. **只焊电源**：12V 限流 50mA 从 PACK+ 供电 → 量 3.3V、REGOUT(≈3.3V)、I2C 上拉为高；
2. **接 MCU**：烧录固件，串口应每秒输出一帧（此时电压为 0，属正常）；
3. **接假电池组**：三路可调电源串联（各 3.9V / 限流 100mA）接到 VC0~VC3，
   串口应显示 ≈3900/3900/3900，总压 ≈11700；
4. **接真电池**：先接 B-，再依次 B1、B2、B+（**顺序反了会烧 AFE**），最后插 XT30。

## 3. 校准

### 3.1 电压
1. 静置，用 4 位半万用表逐节量电芯实际电压；
2. 对比串口读数，若偏差 >2mV，按下面修正：

```c
/* bms_config.h */
#define BMS_CAL_CELL_GAIN      1.0006f   // 实测/读数
#define BMS_CAL_CELL_OFFSET_MV 1         // 固定偏差，mV
```

3. 注意：AFE 的增益/偏置是出厂校准值（代码自动读 `ADCGAIN1/2`、`ADCOFFSET`），
   一般不需要动，偏差大先查 **RC 滤波电阻是否一致**、**地线压降**。

### 3.2 电流
1. **零点**：不接负载，读串口 `I`，若 |I|>20mA，说明采样电阻焊接/走线有问题，
   或在 `BMS_CURRENT_SIGN` 附近加一个 `+ offset` 修正；
2. **满量程**：接电子负载 5A，比较读数与负载显示，误差应 <1%；
3. 若符号相反（充电显示负），把 `BMS_CURRENT_SIGN` 改成 `-1`。

### 3.3 温度
1. 冰水混合物（0℃）读数应为 0±1℃；
2. 室温（用温度计对比）25℃ 左右；
3. 偏差 >2℃ 时改 `BQ_THERMISTOR_BETA`（常见 3435/3950）或 NTC 分压上拉阻值。

## 4. 保护注入测试

> **用假电池组做**（三路可调电源），不要拿真电池做短路测试。

| 测试 | 方法 | 预期 |
|---|---|---|
| 过压 OV | 把某一路电源从 3.9V 升到 4.30V | 2s 内 CHG 关断，LED 快闪，故障位 `0x0001` |
| 过压恢复 | 降回 4.10V 并等 3s | 故障清除，CHG 恢复 |
| 欠压 UV | 降到 2.75V | DSG 关断，故障位 `0x0002` |
| 过流 OCD | 先临时把 `CFG_OCD_MA` 改成 3000 编译，接 2Ω 负载（≈6A） | 80ms 内 DSG 关断 |
| 短路 SCD | 临时把 `CFG_SCD_MA` 改成 5000，用 MOS 开关对 1Ω 放电 | 200µs 级关断（示波器看） |
| 过温 | 热风枪吹 NTC 到 50℃ | 故障位 `0x0010` |
| 低温禁充 | 冰袋敷 NTC 到 -5℃ | 只禁充（`0x0020`），放电正常 |
| 通讯故障 | 拔掉 SDA | 5 次失败后故障 `0x0080`，FET 保持最后状态（AFE 仍在保护） |

测试完**务必把阈值改回** `bms_config.h` 的默认值。

## 5. 均衡验证

1. 三节都充到 3.95V，单独给第 1 节补到 4.05V（制造 100mV 压差）；
2. 静置 5 分钟 → 串口 `bal` 字段应变为 `01`（第 1 节）；
3. 用钳形表/万用表量均衡电阻两端，应有 ≈3.5V（约 35mA）；
4. 30s 后应自动关闭 10s 再开（占空比）；
5. 若一直不均衡：检查 `|I|` 是否 <50mA、温度是否 10~45℃、最高节是否 >3.90V。

## 6. SOC 与容量

1. 满充后静置 30 分钟，串口 SOC 应 ≈100%；
2. 以 0.2C（700mA）放电到 2.8V 截止，记录放出容量 Ah；
3. 与 `BMS_CELL_CAPACITY_MAH` 对比，偏差 >10% 时用实测值更新，并调用
   `SOC_SetCapacity()`（或在 config 里改）；
4. 重复 3 次循环，观察 SOC 是否在满充/放空时自动对齐。

## 7. 验收标准

| 项目 | 标准 |
|---|---|
| 单体电压 | 误差 ≤ ±3mV（校准后） |
| 总压 | ≤ ±20mV |
| 电流 | 0~10A 内 ≤ ±1% |
| 温度 | ≤ ±1.5℃ |
| OV/UV 动作 | 延时误差 <20% |
| OCD/SCD | 能可靠关断，无炸机 |
| 待机电流 | MCU 72MHz 下 ≈30mA（换 L431 可到 µA 级） |
| 连续运行 24h | 无看门狗复位、SOC 漂移 <3% |

## 8. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 串口无输出 | 波特率/接线反、USART1 中断没开 | 先量 TX 是否有电平变化 |
| `BQ_Init` 返回 0 | I2C 地址错（0x08 vs 0x10）、上拉没焊、AFE 没 BOOT | 逻辑分析仪看是否有 ACK |
| 电压全 0 | VC 线没接、RC 滤波开路、3S 时 VC4/VC5 没短接 | 逐点量 VC 引脚电压 |
| 温度 -127℃ | NTC 没接/短路、TS1 配置错 | 量 TS1 分压，25℃ 应 ≈1.65V |
| CHG 一直不开 | 低温保护、OV 未清、充电器检测脚 | 看 `faults` 字段，逐位排除 |
| 电流符号反 | 采样电阻在正极侧 / 走线顺序反 | 改 `BMS_CURRENT_SIGN` 或改硬件 |
| SOC 掉得特别快 | CC 读取太慢（丢了 3/4 数据） | 确认 100ms 任务在跑 |
| 均衡发烫 | 均衡电阻功率不够 | 换 1/2W，或降均衡电流（加大电阻） |
| 一上电就复位 | IWDG 在 `BMS_Init` 前就超时 / 中断卡死 | 调试时先 freeze IWDG |

## 9. 安全红线

1. **绝不在真电池上做短路测试**；
2. 焊接/拆线前先断开负载，拔掉 XT30；
3. 18650 正负极别用金属镊子同时碰；
4. 电池鼓包/发热立即隔离到沙桶，不要放室内；
5. 长时间无人值守测试时，电池放防火袋里。
